# A systems-modelling approach to predict biological responses to extreme heat

[![DOI](https://zenodo.org/badge/750640367.svg)](https://doi.org/10.5281/zenodo.17316595)

This is the online GitHub repository hosting the code and data used for the paper:

Noble *et al.* 2025. A systems-modelling approach to predict biological responses to extreme heat. Trends in Ecology and Evolution, under review.

Please get in touch with Daniel Noble (daniel.noble@anu.edu.au) and Mike Kearney (m.kearney@unimelb.edu.au) if you have any questions about the code or the models.

# How to use this repository

You can download this repository as a zip file, or clone it using Git. To download the repository as a zip file, click the green "Code" button at the top right of this page, and select "Download ZIP". 

Set your working directory to the root of the repository. You can then follow the rendered and annotated [code](https://daniel1noble.github.io/thermal_tol_interactions/) document. If you cloned/downloaded the repo you can also run the code and reproduce the results in the paper by working through the `supp.qmd` file in the `docs/` folder.
